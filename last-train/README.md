# Последний поезд — первый играбельный прототип

Небольшая 2D survival-игра с видом сбоку. Поезд — ваша единственная база в разрушенном мире.

## Запуск
Откройте `last-train/index.html` в браузере. Никакой установки пакетов и подключения к интернету не требуется.

Либо из папки `last-train` запустите `python -m http.server 8000` и откройте http://localhost:8000/.

## 🌐 Сетевой кооператив по Wi-Fi / LAN

Начиная с этой версии несколько игроков могут **одновременно управлять одним поездом** в общей комнате. Сетевой режим рассчитан на локальную сеть: **один ПК запускает сервер, остальные заходят в браузере с ноутбука или телефона**. Установка JavaScript-пакетов и Python-библиотек не требуется — используется только Python 3.10+ из стандартной библиотеки.

### Запуск сервера

Сначала переключитесь на ветку игры и обновите её:

```bash
git switch igra_zhenya
git pull origin igra_zhenya
cd last-train
```

**Windows** (PowerShell или командная строка):

```powershell
py server.py --host 0.0.0.0 --port 8000
```

**Linux / Ubuntu:**

```bash
python3 server.py --host 0.0.0.0 --port 8000
```

На компьютере-сервере откройте **http://localhost:8000**. На другом устройстве в той же сети откройте **http://IP_КОМПЬЮТЕРА:8000** — например, http://192.168.1.50:8000 (замените адрес на реальный IP своего ПК). **Не используйте localhost или 127.0.0.1 на телефоне**, потому что они указывают на сам телефон.

Чтобы узнать IP: Windows — `ipconfig` (адрес IPv4 активного адаптера); Linux — `hostname -I` или `ip -4 addr`. Компьютер должен оставаться включённым, а сервер — работать.

### Подключение игроков

1. Первый игрок нажимает **«Создать комнату»**, вводит имя и получает **шестисимвольный код**.
2. Остальные открывают адрес сервера по IP, вводят имя и код, затем нажимают **«Войти в комнату»**.
3. Список участников и чат видны всем. Можно путешествовать, строить вагоны, исследовать станции и совместно отстреливать зомби.

Поддерживается до **8 человек в комнате**. Все припасы, здоровье поезда, действия на станциях, убийства и координаты зомби хранятся **на сервере**; игроки не могут независимо потратить одни и те же ресурсы или дважды собрать одну и ту же добычу. Поезд отправляет первый игрок, нажавший «Продолжить путь»; остальные наблюдают за той же поездкой. При выходе из комнаты можно вернуться в отдельный одиночный прогресс.

### Если телефон не подключается

- Убедитесь, что устройства в одной обычной Wi-Fi/локальной сети (не в изолированной гостевой сети), и используется **IP компьютера с сервером**, а не `localhost`.
- Проверьте, что сервер запущен именно через `server.py` и в терминале не отображается ошибка. Команда `python -m http.server` **не включает** многопользовательский API.
- Проверьте Windows Defender Firewall: разрешите входящие TCP-соединения на порт 8000 для частной сети. Администратор может добавить правило через PowerShell: `New-NetFirewallRule -DisplayName 'Last Train LAN' -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private`.
- На Ubuntu при включённом UFW разрешите порт: `sudo ufw allow 8000/tcp`. Проверьте VPN и изоляцию клиентов Wi-Fi на роутере.
- Если локальный порт уже занят, запустите `python3 server.py --port 8080` (Windows: `py server.py --port 8080`) и подключайтесь по новому порту.
- Это **LAN-кооператив**, не публичный интернет-сервер: соединение по обычному HTTP рассчитано на доверенную локальную сеть. Не открывайте порт напрямую в интернет без TLS и отдельной защиты доступа.

**Важно:** сетевые комнаты и их прогресс пока хранятся в оперативной памяти сервера, поэтому **после перезапуска `server.py` они обнуляются**. Обычное одиночное сохранение браузера работает отдельно и не перезаписывается сетевой игрой.

Проверка сетевого API без сторонних зависимостей:

```bash
python -m unittest discover -s tests -v
```

Есть также отдельный GitHub Actions workflow `.github/workflows/last-train-lan.yml` для этих тестов.

### Одиночный режим

Для игры без сети можно, как и раньше, просто открыть `index.html` из папки `last-train/`. Подключаться к серверу не нужно.

## Графика и состав
- Стартовый поезд теперь включает **7 единиц подвижного состава**: локомотив, тендер, жилой и пассажирский вагоны, склад, кухню и грузовую платформу.
- Каждый тип имеет собственный рисунок: окна, освещение, дверные проёмы, крышу, колёса, сцепки и металлические панели.
- Детализированный дизельный локомотив, фары, дым, тени, рельсы и постапокалиптические станции.
- У каждой из шести остановок свой силуэт на заднем плане: цистерны, больница, домики, завод, блокпост или радиовышка. Даже на обычной остановке вдали видны заражённые.
- **Осмотр длинного поезда:** кнопки «К хвосту» и «К локомотиву», перетаскивание мышью/пальцем, стрелки влево/вправо.
- Старые сохранения автоматически получают базовые вагоны без потери добычи, улучшений и прогресса.
- Визуальные эффекты работают через Canvas без тяжёлых ассетов и фреймворков, ограничение перерисовки ~30 FPS.

## Персонажи и визуализация

В игре есть **шесть внешне различных видов мутантов** (не цветовые варианты одного спрайта):

- **Шатун** — худой сутулый заражённый, выступающие рёбра, длинные руки, неправильная походка.
- **Ползун** — четвероногий мутант с вытянутым туловищем и нечеловеческой постановкой конечностей.
- **Громила** — тяжёлый массивный противник с костными пластинами и огромными кулаками.
- **Прыгун** — тонкий хищник с длинными суставчатыми ногами и прыгающим движением.
- **Спороносец** — мутант с разросшимися грибными структурами, щупальцами и спорами.
- **Двуглавый** — сросшееся существо с двумя головами и третьей рукой.

Зомби разных видов различаются **не только внешностью**: у них разные скорость, количество здоровья и наносимый урон. Ползун и Прыгун быстрее, Громила медленнее, но опаснее и значительно прочнее. Зомби идут к локомотиву, атакуют при сближении и получают урон от выстрелов.

**Выжившие внутри поезда** визуализируются как люди с разной одеждой и ролями: машинист в кабине, пассажиры в жилых вагонах, повар, рабочие, медик, охранник и фермер в специализированных вагонах. Их можно увидеть сквозь окна и на открытой грузовой платформе. На экране отображается не больше персонажей, чем указано в численности экипажа. После гибели или пополнения людей состав персонажей меняется. Персонажи слегка движутся (дыхание/жесты).

Никакие дополнительные библиотеки, картинки или сетевые запросы для графики не нужны: всё рисуется средствами Canvas 2D (`visuals.js`, `characters.js`). Для осмотра состава — перетаскивание изображения мышью, стрелки `←`/`→` или кнопки.

## Новая механика зомби и остановок

**Как увидеть зомби:** на начальной станции силуэты заражённых видны вдали. Первый переезд (из первого дня во второй) **гарантированно запускает нападение**, чтобы можно было сразу испытать бой. В последующие дни встречи происходят случайно, в том числе после рискованных решений на станциях.

**Как стрелять:** нажмите прямо на зомби в области игрового поля (мышью либо пальцем). Тратится 1 патрон за выстрел; у каждого вида своя полоска здоровья. Улучшение оружия увеличивает урон. Зомби идут к локомотиву и бьют по нему, когда подходят. Когда все убиты, начисляются убийства и металлолом, а атака завершается. При нехватке патронов доступна **«Автооборона»** — она отражает атаку, но может серьёзно повредить состав.

**Типы остановок:** разбитое депо, больница, посёлок, завод, военный блокпост и радиостанция. На каждой есть 3 **разных по последствиям решения**: поиск еды/топлива, получение оружия или медикаментов, ремонт, приглашение беженцев, разведка безопасного маршрута и т. п. Рискованные действия могут привлечь новую волну зомби. Можно выполнить **одно** основное действие на остановке, либо воспользоваться кнопкой быстрого обыска. Варианты и последствия меняются от станции к станции, станции не повторяются подряд.

Сохраняются здоровье, припасы, убийства, прогресс и состояние нападения. Все механики работают без тяжёлых сторонних библиотек.

## Что реализовано
- Путешествие между заброшенными станциями; каждый переход расходует топливо и еду.
- Исследование станции с добычей металлолома, еды, топлива, медикаментов и риском потерь.
- Случайные события и нападения мутантов с расчётом силы обороны, расходом патронов и повреждениями.
- Строительство четырёх специализированных вагонов: ферма, медпункт, мастерская, охранный.
- Улучшение оружия, брони, производство патронов, ремонт, пополнение команды, обмен ресурсов.
- Проигрыш при разрушении поезда или гибели всей команды.
- Автосохранение через localStorage, кнопки сохранения и новой игры.
- Простая Canvas-графика без сторонних зависимостей. Адаптация интерфейса под узкий экран.

## Непрерывная анимация мира

Фон теперь **генерируется в непрерывных мировых координатах** и прокручивается плавно в течение всей поездки:
- дальние горы состоят из непрерывного рельефа (интерполированный шум), а не коротких повторяющихся силуэтов;
- ближние холмы, заброшенный город, опоры связи, трава, шпалы и пыль смещаются на разных скоростях;
- здания и другие объекты не телепортируются обратно из-за смены индекса при прокрутке;
- отправная станция постепенно остаётся позади, следующая станция заранее появляется справа и приближается к составу;
- внешний вид прибывающей станции соответствует локации, которая затем открывается в интерфейсе;
- при остановке мир замирает без скачка координат.

Состав по-прежнему удерживается камерой примерно в одной области экрана, а ближайшее окружение плавно движется справа налево — как при наблюдении из движущегося поезда. Визуальные эффекты реализованы на Canvas 2D без сторонних библиотек.

## Анимация поездки

После нажатия **«Продолжить путь»** запускается примерно пятисекундный переезд:
поезд плавно разгоняется, колёса начинают вращаться, дым становится гуще,
пейзаж, опоры, рельсовые шпалы и пыль движутся с разной скоростью (параллакс).
Вагонный состав слегка покачивается, в интерфейсе показываются скорость и индикатор пути.
Перед прибытием поезд плавно тормозит.

Ресурсы, пройденные километры и событие следующей остановки рассчитываются **после**
анимации. Пока состав в пути, другие игровые действия заблокированы — расход ресурсов
и строительство не могут сработать несколько раз. Переезд не записывается в сохранение,
пока не завершён: обновление вкладки во время анимации вернёт к исходной станции
без списания топлива. После прибытия прогресс автосохраняется.

Если в операционной системе включено «уменьшение движения», длительность анимации
сокращается примерно до 0,3 секунды. Всё работает без дополнительных библиотек.

## Управление
Пробел — продолжить путь; E — быстрый обыск; F — автооборона; во время нападения **нажимайте на зомби на Canvas, чтобы стрелять**. Стрелки ←/→ — осмотреть состав, кроме времени нападения, когда камера остаётся у локомотива. Все основные действия доступны кнопками.

## Границы прототипа
Это всё ещё ранний 2D-прототип: стрельба по зомби работает через клик по цели, но полноценного перемещения персонажа по вагонам или отдельных 2D-сцен вылазки пока нет. Графика рисуется средствами Canvas 2D без внешних ресурсов.
