# FORBIDDEN FRUIT — оригинальная игра (восстановлена)

Восстановлена **первая игровая версия** из коммита [`34d5fbb`](https://github.com/swrobotcompany-dev/zhenya/commit/34d5fbb91cc619e9c30a26ef8b26500f2545fea5), а не поздняя переработка WorldHarvest.

Маленькое 3D-приключение про лисёнка. Выбери **Обыкновенный лес**, **Лунный сад** или **Золотую поляну**, собери семь волшебных плодов, убегай от духа тумана и возвращайся к порталу. Сохранены исходная стилистика, персонаж, три биома, музыка и игровой процесс.

## Запуск на localhost и с другого ПК по IP

Нужен Python 3, **установка библиотек не требуется**. В каталоге игры запусти:

```bash
python server.py
```

На Linux также подойдёт `python3 server.py`. Сервер покажет две ссылки, например:

```text
На этом ПК: http://localhost:8000
На другом ПК в той же сети: http://192.168.1.42:8000
```

На компьютере с сервером зайди на **http://localhost:8000**; с другого компьютера, подключённого к той же локальной сети, открой **http://IP_КОМПЬЮТЕРА_С_СЕРВЕРОМ:8000** (адрес выше — только пример). Введи `http://` явно, не `https://`. **localhost на втором ПК указывает на второй ПК, а не на сервер.**

По умолчанию сервер слушает **0.0.0.0:8000** (все IPv4-интерфейсы). Это позволяет другим компьютерам открыть ту же страницу, **но каждый играет отдельно — общего мира и мультиплеера нет**.

Если с другого компьютера страница не открывается:

1. Убедись, что оба ПК подключены к одной сети и не включена изоляция клиентов Wi-Fi / гостевая сеть.
2. Узнай локальный IPv4 на ПК с сервером: `ipconfig` (Windows) или `ip -4 addr` (Linux). Не используй `127.0.0.1` и не путай с адресом второго компьютера.
3. Разреши **входящие TCP-подключения на порт 8000** в брандмауэре ПК с сервером для своей доверенной частной сети. Не открывай порт на роутере в интернет.
4. Убедись, что сервер запущен и не выдал сообщение `Address already in use`. Если порт занят: `python server.py --port 8080` и открой соответствующую ссылку с портом 8080.

Чтобы снова ограничить доступ одним компьютером: `python server.py --host 127.0.0.1`.

Сервер предназначен для **доверенной домашней сети**, не для публичного доступа. WebSocket и сетевое лобби не требуются.

> Важное ограничение оригинальной версии: 3D-движок Three.js r128 загружается из CDN, а шрифты — из Google Fonts. Поэтому для первого запуска **нужен доступ к интернету**. Сам игровой сервер работает локально.

## Оптимизация графики и кеш

В стартовом меню появилась настройка **«Качество графики»**:

- **Авто (по умолчанию)** — выбирает экономный или сбалансированный профиль по характеристикам компьютера; при заметных просадках FPS плавно снижает внутреннее разрешение.
- **Экономное** — 30 FPS, более низкое разрешение, меньше растительности и частиц, облегчённые тени; подходит для старых ноутбуков и слабой встроенной графики.
- **Сбалансированное** — 60 FPS, тени 1024 px и умеренное разрешение.
- **Высокое** — графика максимально близка к исходной версии.

Выбор сохраняется в `localStorage` браузера и применяется при запуске следующего мира. При зависаниях или сильной просадке FPS сначала выбери **Экономное**.

Внутренние изменения: деревья объединены в `THREE.InstancedMesh` (меньше draw calls), одинаковые текстуры свечения создаются однократно, повторное создание объектов в цикле камеры уменьшено, а тени обновляются реже на экономном/сбалансированном профиле.

`server.py` кеширует подготовленный HTML и gzip-версию **в памяти процесса**, сжимает отдачу по HTTP, передаёт `ETag` и `Last-Modified` и отвечает `304 Not Modified` при повторном запросе неизменённой страницы. Это ускоряет **загрузку страницы**, а не само выполнение WebGL. Браузер продолжает самостоятельно кешировать Three.js и шрифты с внешних CDN — для первого запуска им нужен интернет. Кеш HTML не обеспечивает полноценную офлайн-игру.

## Управление

- **WASD / стрелки** — перемещение лисёнка.
- **Shift / пробел** — ускорение; следи за выносливостью.
- **P / Escape** — пауза.
- **M** — включить/выключить звук.
- **R** — вернуться в меню после победы или поражения.

Плоды подбираются автоматически, если подойти к ним достаточно близко. Когда все 7 плодов собраны, открывается портал в центре карты. После игры сохраняется **лучший результат в текущем браузере**, отдельно для каждого мира.

## Что изменено по сравнению с оригиналом

1. Добавлен простой HTTP-сервер для localhost и просмотра игры с других устройств по LAN без мультиплеера.
2. Добавлена пауза по Escape; убрано повторное срабатывание P при удержании.
3. После конца игры показываются результат и рекорд, сохраняемый локально.
4. Исправлена редкая ситуация, когда после потери последнего сердца ещё можно было успеть выиграть.
5. Добавлена подсказка клавиши R для возврата к выбору мира.

Изначальный код игры оставлен **единым HTML-файлом `index.html`**, чтобы не терять графику/эффекты при очередном переписывании. Для оригинальной исторической версии смотрите вышеуказанный коммит.
