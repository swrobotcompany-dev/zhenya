# 🌍 WorldHarvest

Небольшая браузерная 2D-игра на выживание: путешествуй между мирами, собирай плоды, следи за здоровьем и сытостью.

## Запуск

Открой файл `index.html` в браузере — никаких библиотек или установки не требуется.

Опционально, чтобы запустить на локальном сервере:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000. На другом устройстве в той же сети можно зайти через локальный IP компьютера.

## Игровая механика

- 🌿 **Зелёный мир:** яблоки, деревья, колючки.
- ☀️ **Пустыня:** плоды кактуса, жара и колючки.
- ❄️ **Ледяной мир:** ягоды, холод и ледяные ловушки.
- Сбор плодов восстанавливает сытость и приносит очки.
- Для открытия портала собери **3 плода текущего мира**, затем подойди к порталу и нажми **E**.
- Сытость снижается со временем. Когда она достигает нуля, уменьшается здоровье.
- Опасные объекты наносят урон, миры обладают собственной сложностью.
- После смерти можно начать заново.

## Управление

| Действие | ПК | Телефон / планшет |
| --- | --- | --- |
| Движение | WASD или стрелки | Экранные стрелки |
| Сбор плода / портал | E | Кнопка «Действие» |
| Пауза | Escape | Кнопка Ⅱ |

## Структура

- `index.html` — игровое поле и интерфейс
- `styles.css` — адаптивное оформление
- `game.js` — игровой цикл, миры, сбор предметов и переходы
