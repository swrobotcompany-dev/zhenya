# FORBIDDEN FRUIT — оригинальная игра (восстановлена)

Восстановлена **первая игровая версия** из коммита [`34d5fbb`](https://github.com/swrobotcompany-dev/zhenya/commit/34d5fbb91cc619e9c30a26ef8b26500f2545fea5), а не поздняя переработка WorldHarvest.

Маленькое 3D-приключение про лисёнка. Выбери **Обыкновенный лес**, **Лунный сад** или **Золотую поляну**, собери семь волшебных плодов, убегай от духа тумана и возвращайся к порталу. Сохранены исходная стилистика, персонаж, три биома, музыка и игровой процесс.

## Запуск на localhost

Нужен Python 3, **установка библиотек не требуется**.

```bash
python server.py
```

Открой в браузере **http://localhost:8000**. На Linux также работает `python3 server.py`.

Если 8000 занят: `python server.py --port 8080`, затем **http://localhost:8080**.

Сервер слушает **только 127.0.0.1**. Другие компьютеры по локальной сети не подключаются; здесь нет мультиплеера, WebSocket и лобби.

> Важное ограничение оригинальной версии: 3D-движок Three.js r128 загружается из CDN, а шрифты — из Google Fonts. Поэтому для первого запуска **нужен доступ к интернету**. Сам игровой сервер работает локально.

## Управление

- **WASD / стрелки** — перемещение лисёнка.
- **Shift / пробел** — ускорение; следи за выносливостью.
- **P / Escape** — пауза.
- **M** — включить/выключить звук.
- **R** — вернуться в меню после победы или поражения.

Плоды подбираются автоматически, если подойти к ним достаточно близко. Когда все 7 плодов собраны, открывается портал в центре карты. После игры сохраняется **лучший результат в текущем браузере**, отдельно для каждого мира.

## Что изменено по сравнению с оригиналом

1. Добавлен простой HTTP-сервер только для localhost.
2. Добавлена пауза по Escape; убрано повторное срабатывание P при удержании.
3. После конца игры показываются результат и рекорд, сохраняемый локально.
4. Исправлена редкая ситуация, когда после потери последнего сердца ещё можно было успеть выиграть.
5. Добавлена подсказка клавиши R для возврата к выбору мира.

Изначальный код игры оставлен **единым HTML-файлом `index.html`**, чтобы не терять графику/эффекты при очередном переписывании. Для оригинальной исторической версии смотрите вышеуказанный коммит.
